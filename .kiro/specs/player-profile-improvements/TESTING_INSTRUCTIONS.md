# Инструкции по мануальному тестированию

## 🎯 Цель

Задача 16.4 требует **мануального тестирования** всех реализованных функций профиля игрока на различных браузерах, устройствах и сетевых условиях.

## 📋 Что подготовлено

Для вас созданы следующие файлы:

1. **MANUAL_TESTING_CHECKLIST.md** - детальный чек-лист со всеми проверками
2. **MANUAL_TESTING_REPORT.md** - шаблон отчёта для заполнения
3. **automated-ui-checks.js** - скрипт для базовых автоматизированных проверок

## 🚀 Как начать тестирование

### Шаг 1: Подготовка окружения

```bash
# 1. Убедитесь, что dev-сервер запущен
npm run dev

# 2. Откройте приложение в браузере
# http://localhost:3000

# 3. Войдите в систему под тестовым аккаунтом
```

### Шаг 2: Откройте чек-лист

Откройте файл `MANUAL_TESTING_CHECKLIST.md` и следуйте инструкциям для каждого браузера и устройства.

### Шаг 3: Выполните тестирование

#### Десктопные браузеры (обязательно)
- ✅ Google Chrome (последняя версия)
- ✅ Mozilla Firefox (последняя версия)
- ✅ Safari (последняя версия, macOS)

#### Мобильные устройства (обязательно)
- ✅ iPhone (Safari iOS)
- ✅ Android Phone (Chrome)

#### Сетевые условия (обязательно)
- ✅ Slow 3G (эмуляция в DevTools)
- ✅ Socket.IO disconnect/reconnect
- ✅ Нестабильное соединение

### Шаг 4: Заполните отчёт

По мере тестирования заполняйте `MANUAL_TESTING_REPORT.md`:
- Отмечайте Pass/Fail для каждого теста
- Записывайте найденные проблемы
- Добавляйте комментарии и скриншоты

### Шаг 5: Запустите автоматизированные проверки (опционально)

```bash
node .kiro/specs/player-profile-improvements/automated-ui-checks.js
```

Это выполнит базовые проверки структуры DOM и CSS свойств.

## 🔍 Что тестировать

### Основные компоненты

1. **FriendshipBadge** (4 состояния):
   - Не друг (+) → Заявка отправлена (○ желтый)
   - Заявка получена (○ синий) → Друг (✓ зеленый)
   - Друг (✓ зеленый) → Не друг (+)

2. **MessageButton**:
   - Открывает окно чата
   - Стиль идентичен кнопке "Редактировать профиль"

3. **FriendNoteField** (Discord-style):
   - Без бордера по умолчанию
   - Бордер при hover/focus
   - Автосохранение через ~500ms
   - Лимит 500 символов

4. **MoreMenuButton**:
   - Открывает контекстное меню
   - Содержит: Игнорировать, Заблокировать, Пожаловаться

5. **RegistrationDate**:
   - Формат: "Участник с DD MMM YYYY г."
   - Русские сокращения месяцев

## 🎨 Как эмулировать условия

### Медленное соединение (Chrome)
1. F12 → Network tab
2. Throttling → Slow 3G
3. Тестируйте загрузку и операции

### Медленное соединение (Firefox)
1. F12 → Network tab
2. Throttling → GPRS
3. Тестируйте загрузку и операции

### Отключение Socket.IO
1. Остановите сервер: `Ctrl+C` в терминале с `npm run dev`
2. Или заблокируйте WebSocket в DevTools
3. Проверьте уведомления об ошибках

### Мобильные устройства (эмуляция)
1. Chrome DevTools: F12 → Toggle device toolbar (Ctrl+Shift+M)
2. Выберите устройство: iPhone 12 Pro, Pixel 5, iPad Pro
3. Тестируйте touch-взаимодействие
