# Task 15.3: Focus Management Implementation

## Описание
Добавлен focus management для FullProfileModal и MoreMenuButton согласно требованиям accessibility.

## Реализованные изменения

### 1. Создан хук `useFocusTrap` (`client/src/hooks/useFocusTrap.js`)
- Реализует focus trap для модальных окон
- Предотвращает выход фокуса за пределы контейнера при навигации Tab/Shift+Tab
- Поддерживает все focusable элементы (кнопки, ссылки, инпуты, textarea, select)
- Корректно обрабатывает disabled элементы

**Функциональность:**
- При нажатии Tab на последнем элементе → фокус переходит на первый элемент
- При нажатии Shift+Tab на первом элементе → фокус переходит на последний элемент
- Активируется только когда `isActive === true`

### 2. Обновлен `FullProfileModal` (`client/src/components/profile/FullProfileModal.jsx`)

**Добавлено:**
- Импорт хука `useFocusTrap`
- Refs для focus management:
  - `modalRef` - ссылка на контейнер модального окна
  - `closeButtonRef` - ссылка на кнопку закрытия
  - `triggerElementRef` - ссылка на элемент, который открыл модал

**Focus management при открытии модала:**
- Сохраняется ссылка на элемент, который открыл модал (`document.activeElement`)
- После завершения анимации (100ms) фокус переводится на кнопку закрытия
- Активируется focus trap через хук `useFocusTrap`

**Focus management при закрытии модала:**
- Фокус возвращается на элемент, который открыл модал (`triggerElementRef.current`)
- Работает для всех способов закрытия: клик на кнопку, Escape, клик на backdrop

### 3. Обновлен `MoreMenuButton` (`client/src/components/profile/MoreMenuButton.jsx`)

**Улучшен возврат фокуса на кнопку "Ещё" при закрытии меню:**
- При клике вне меню
- При нажатии Escape
- При клике на backdrop (мобильная версия)
- После выбора любого действия из меню:
  - Игнорировать/Разигнорировать
  - Заблокировать/Разблокировать
  - Пожаловаться
  - Пригласить в клан

## Соответствие требованиям

### Requirement: Accessibility (Task 15.3)

✅ **При открытии модала фокус переходит на первый focusable элемент**
- Реализовано через `useEffect` с задержкой 100ms для завершения анимации
- Фокус устанавливается на кнопку закрытия (`closeButtonRef`)

✅ **При закрытии модала фокус возвращается на trigger элемент**
- Сохраняется ссылка на `document.activeElement` при открытии
- Фокус восстанавливается в функции `handleClose()`

✅ **Реализован focus trap**
- Создан переиспользуемый хук `useFocusTrap`
- Tab/Shift+Tab циклически перемещают фокус внутри модала
- Предотвращается выход фокуса за пределы модального окна

✅ **При закрытии контекстного меню фокус возвращается на кнопку "Ещё"**
- Добавлен возврат фокуса во все обработчики закрытия меню
- Работает для всех способов закрытия и всех действий меню

## Технические детали

### useFocusTrap Hook
```javascript
useFocusTrap(containerRef, isActive)
```
- `containerRef` - React ref на контейнер
- `isActive` - boolean флаг активации trap

### Focusable элементы
Хук обрабатывает следующие селекторы:
- `a[href]`
- `button:not([disabled])`
- `textarea:not([disabled])`
- `input:not([disabled])`
- `select:not([disabled])`
- `[tabindex]:not([tabindex="-1"])`

### Keyboard Navigation
- **Tab** - переход к следующему focusable элементу
- **Shift+Tab** - переход к предыдущему focusable элементу
- **Escape** - закрытие модала/меню с возвратом фокуса

## Тестирование

### Ручное тестирование
1. Открыть профиль игрока
2. Проверить, что фокус на кнопке закрытия
3. Нажать Tab несколько раз - фокус должен циклически перемещаться внутри модала
4. Нажать Escape - модал закрывается, фокус возвращается на trigger
5. Открыть меню "Ещё"
6. Нажать Escape или выбрать действие - фокус возвращается на кнопку "Ещё"

### Проверка accessibility
- Навигация только с клавиатуры (без мыши)
- Проверка с screen reader (NVDA/JAWS)
- Проверка видимости фокуса (focus ring)
