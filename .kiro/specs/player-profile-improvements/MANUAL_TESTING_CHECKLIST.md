## 🌐 3. Сетевые условия

### 3.1 Медленное соединение (Slow 3G)

**Как эмулировать:**
- Chrome DevTools → Network → Throttling → Slow 3G
- Firefox DevTools → Network → Throttling → GPRS

**Тесты:**
- [ ] Открытие профиля: показывается loader
- [ ] Отправка заявки в друзья: показывается loader на бейдже
- [ ] Сохранение заметки: показывается индикатор сохранения
- [ ] Retry logic срабатывает при таймауте
- [ ] Уведомления об ошибках показываются корректно
- [ ] UI не блокируется во время загрузки

---

### 3.2 Отключение Socket.IO

**Как эмулировать:**
- Остановить сервер Socket.IO
- Или заблокировать WebSocket в DevTools

**Тесты:**
- [ ] Показывается уведомление "Соединение потеряно"
- [ ] Попытка отправить заявку в друзья: показывается ошибка
- [ ] Попытка сохранить заметку: показывается ошибка
- [ ] При восстановлении соединения: показывается "Соединение восстановлено"
- [ ] Данные профиля перезагружаются после восстановления
- [ ] Retry logic работает корректно

---

### 3.3 Нестабильное соединение

**Как эмулировать:**
- Периодически включать/выключать сеть
- Использовать Network Link Conditioner (macOS)

**Тесты:**
- [ ] Операции повторяются автоматически после восстановления
- [ ] Не создаются дубликаты заметок
- [ ] Не отправляются дубликаты заявок в друзья
- [ ] Состояние UI синхронизируется с сервером

---

## 🔍 4. Edge Cases (Граничные случаи)

### 4.1 Очень длинные заметки
- [ ] Ввод 500 символов: сохраняется корректно
- [ ] Попытка ввести 501 символ: блокируется
- [ ] Вставка текста >500 символов: обрезается до 500
- [ ] Счетчик показывает "500 / 500"

### 4.2 Быстрые клики (Rapid clicking)
- [ ] Быстрые клики на FriendshipBadge: не создают дубликаты заявок
- [ ] Быстрые клики на MessageButton: не открывают несколько окон чата
- [ ] Быстрые клики на MoreMenuButton: меню не дергается

### 4.3 Множественные модалы
- [ ] Открыть профиль A
- [ ] Открыть профиль B поверх A
- [ ] Закрыть B: A остается открытым
- [ ] Escape закрывает только верхний модал

### 4.4 Специальные символы в заметках
- [ ] HTML теги: `<script>alert('xss')</script>` → экранируются
- [ ] Эмодзи: `😀🎉🔥` → сохраняются корректно
- [ ] Unicode: `Привет мир 你好世界` → сохраняется корректно
- [ ] Переносы строк: многострочный текст → сохраняется

## 🚀 7. Как запустить тестирование

### Подготовка окружения
```bash
# 1. Запустить dev-сервер
npm run dev

# 2. Открыть приложение в браузере
# http://localhost:3000

# 3. Войти в систему
# Использовать тестовые аккаунты

# 4. Открыть профиль другого игрока
```

### Эмуляция мобильных устройств (Chrome DevTools)
```
1. F12 → Toggle device toolbar (Ctrl+Shift+M)
2. Выбрать устройство: iPhone 12 Pro, Pixel 5, iPad Pro
3. Тестировать touch-взаимодействие
```

### Эмуляция медленного соединения
```
1. F12 → Network tab
2. Throttling → Slow 3G
3. Тестировать загрузку и операции
```
