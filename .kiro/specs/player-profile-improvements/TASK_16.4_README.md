# Task 16.4: Мануальное тестирование - README

## 📌 Быстрый старт

Задача 16.4 - это **мануальное тестирование**, которое требует участия человека-тестировщика.

### Что создано для вас:

1. **TESTING_INSTRUCTIONS.md** - начните отсюда! Пошаговые инструкции
2. **MANUAL_TESTING_CHECKLIST.md** - детальный чек-лист всех проверок
3. **MANUAL_TESTING_REPORT.md** - шаблон отчёта для заполнения
4. **automated-ui-checks.js** - базовые автоматизированные проверки

### Минимальный набор тестирования:

#### ✅ Обязательно протестировать:
- Chrome (десктоп)
- Firefox (десктоп)
- Safari (десктоп)
- iPhone (Safari iOS)
- Android Phone (Chrome)
- Slow 3G (эмуляция)
- Socket.IO disconnect

#### 📋 Основные проверки:
- FriendshipBadge (4 состояния: +, ○ желтый, ○ синий, ✓)
- MessageButton (открывает чат)
- FriendNoteField (Discord-style, автосохранение)
- MoreMenuButton (контекстное меню)
- RegistrationDate (формат даты)
- Клавиатурная навигация (Tab, Enter, Escape)

### Как начать:

```bash
# 1. Запустите dev-сервер
npm run dev

# 2. Откройте TESTING_INSTRUCTIONS.md
# Следуйте пошаговым инструкциям

# 3. Используйте MANUAL_TESTING_CHECKLIST.md
# Отмечайте выполненные проверки

# 4. Заполняйте MANUAL_TESTING_REPORT.md
# По мере тестирования
```

### Ожидаемое время:

- **Десктопные браузеры**: ~2-3 часа
- **Мобильные устройства**: ~1-2 часа
- **Сетевые условия**: ~1 час
- **Edge cases**: ~1 час
- **Итого**: ~5-7 часов

### Критерии завершения:

✅ Все браузеры протестированы  
✅ Мобильные устройства протестированы  
✅ Сетевые условия проверены  
✅ Отчёт заполнен  
✅ Проблемы задокументированы

## 🚨 Важно понимать

**Это мануальное тестирование** - AI-агент не может:
- Открыть реальные браузеры Chrome, Firefox, Safari
- Использовать реальные iPhone или Android устройства
- Физически проверить touch-взаимодействие
- Оценить UX на реальных устройствах

**AI-агент подготовил**:
- Детальные чек-листы
- Шаблоны отчётов
- Инструкции по тестированию
- Скрипты для базовой автоматизации

**Человек-тестировщик должен**:
- Выполнить все проверки из чек-листа
- Заполнить отчёт о тестировании
- Задокументировать найденные проблемы
- Дать оценку готовности к продакшену
