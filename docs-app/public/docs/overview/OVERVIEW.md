# Обзор проекта PartyChaos

## 🎯 Описание

PartyChaos — это многопользовательская веб-платформа для вечеринок, предоставляющая 4 интерактивные игры с real-time синхронизацией через WebSocket. Проект включает полноценную систему аутентификации, социальные функции (друзья, чаты, кланы), систему достижений и платную подписку.

## 🎮 Доступные игры

### 1. Правда или Действие (Truth or Dare)
Классическая игра с современным подходом:
- Два колеса выбора (категория → задание)
- Таймер на выполнение
- Система голосования
- Страйки и дисквалификация
- Режим "Chaos" для наказанных игроков
- До 20 игроков в комнате

### 2. Alias (Шляпа)
Командная игра на объяснение слов:
- 3 уровня сложности (лёгкий, средний, сложный)
- Неограниченное количество команд
- Настраиваемый таймер (30-120 сек)
- Целевой счёт (10-100 очков)
- Штраф за пропуск (опционально)
- ~12,600 слов в базе

### 3. Codenames (Кодовые имена)
Командная игра с подсказками:
- Две команды (красная и синяя)
- Роли: капитан и оперативники
- 25 карточек на поле
- Таймеры на подсказку и угадывание
- Overtime режим
- Система подтверждения выбора

### 4. Emotional Intelligence
Игра на угадывание эмоций:
- Ведущий выбирает эмоцию
- Игроки угадывают по ассоциациям
- Система голосования
- Автопереход раундов
- Категории эмоций
- Таблица лидеров

### Клиент-серверное взаимодействие

#### REST API
Используется для:
- Аутентификация (регистрация, вход, выход)
- Управление профилем (обновление данных, загрузка аватара)
- Подписка и платежи
- Получение статистики и достижений

#### WebSocket (Socket.IO)
Используется для:
- Real-time синхронизация игровых комнат
- Обновление состояния игры
- Чаты (личные и клановые)
- Уведомления (заявки в друзья, приглашения)
- Онлайн-статус пользователей

## 🔑 Ключевые особенности

### 1. Система аутентификации
- Email + пароль
- OAuth (Discord, Google)
- Верификация email
- Восстановление пароля
- Session-based (httpOnly cookies)
- Rate limiting

### 2. Социальные функции
- Система друзей (заявки, принятие, удаление)
- Приватные чаты между пользователями
- Кланы (создание, управление, чат)
- Профили с биографией и аватарами
- Онлайн-статус и активность

### 3. Геймификация
- Система XP и уровней
- Достижения (5 уровней для каждого)
- Статистика по каждой игре
- Стрики активности
- Таблицы лидеров

### 4. Кастомизация
- Рамки аватара (Frame) для каждой игры
- Кастомизация никнейма (цвета, градиенты, свечение)
- Анимированные эффекты для PRO подписчиков
- Уникальные теги (#0001-#9999)

### 5. Подписка
- **VIP** — базовые преимущества
- **PRO** — расширенные возможности
- Интеграция с Tribute (платёжная система)
- Webhook для автоматической активации

## 🔄 Жизненный цикл запроса

### REST API запрос
```
Браузер → Nginx → Express → Prisma → SQLite
                    ↓
                 Response
                    ↓
Браузер ← Nginx ← Express
```

### WebSocket событие
```
Браузер → Socket.IO Client → Socket.IO Server → In-memory state
                                  ↓
                            Broadcast to room
                                  ↓
Браузер ← Socket.IO Client ← Socket.IO Server
```

### Игровой раунд (пример Alias)
```
1. Игрок нажимает "Угадали" → socket.emit("alias:word:correct")
2. Сервер обновляет счёт команды в памяти
3. Сервер отправляет новое слово → socket.emit("alias:word:next")
4. Сервер broadcast состояние комнаты → io.to(roomCode).emit("alias:room:state")
5. Все клиенты получают обновление и перерисовывают UI
```
