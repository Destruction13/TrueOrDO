# 📖 Руководство по HTML вьюерам

## 🎯 Обзор

Документация TrueOrDO теперь имеет современный веб-интерфейс с красивым дизайном, оптимизированный для удобного восприятия как техническими, так и нетехническими специалистами.

## 🌟 Главные преимущества

### Для нетехнических специалистов
- ✅ Красивый визуальный дизайн без технического шума
- ✅ Интуитивная навигация с иконками и цветовой кодировкой
- ✅ Быстрый поиск по всей документации
- ✅ Адаптивный дизайн для любых устройств
- ✅ Не требует технических знаний для использования

### Для разработчиков
- ✅ Интерактивный API Reference с примерами
- ✅ Цветовая кодировка HTTP методов
- ✅ Быстрая навигация по endpoints и events
- ✅ Интеграция со Swagger UI
- ✅ Поддержка Markdown с подсветкой синтаксиса

## 🚀 Использование

### 1. Главная страница (index.html)

**Назначение**: Точка входа в документацию

**Возможности**:
- Обзор всех разделов документации
- Поиск по ключевым словам
- Быстрые ссылки на важные разделы
- Статистика проекта

**Как использовать**:
1. Откройте `index.html` в браузере
2. Используйте поиск для фильтрации разделов
3. Кликайте на карточки для перехода к документам
4. Используйте быстрые ссылки в верхней части

### 2. Универсальный вьюер (viewer.html)

**Назначение**: Просмотр любых Markdown файлов

**Возможности**:
- Автоматическое оглавление
- Подсветка синтаксиса кода
- Красивое форматирование таблиц
- Плавная прокрутка к разделам

**Как использовать**:
```
viewer.html?file=путь/к/файлу.md
```

**Примеры**:
```
viewer.html?file=technical/AUTH.md
viewer.html?file=guides/START-HERE.md
viewer.html?file=api/API-REFERENCE.md
```

### 3. API вьюер (api/api-viewer.html)

**Назначение**: Интерактивный просмотр API документации

**Возможности**:
- Визуальное отображение endpoints
- Цветовая кодировка HTTP методов (GET, POST, PUT, DELETE)
- Индикаторы авторизации
- Примеры запросов и ответов
- Навигация по Socket.IO событиям
- Поиск по API

**Как использовать**:
1. Откройте `api/api-viewer.html`
2. Используйте боковую навигацию для перехода к разделам
3. Используйте поиск для нахождения конкретных endpoints
4. Кликайте на карточки для просмотра деталей

**Цветовая кодировка методов**:
- 🔵 GET - синий
- 🟢 POST - зеленый
- 🟡 PUT - желтый
- 🟣 PATCH - пурпурный
- 🔴 DELETE - красный

Все вьюеры адаптированы для разных устройств:

### Десктоп (> 1200px)

### Планшет (768px - 1200px)

### Мобильный (< 768px)
- Вертикальная компоновка

## 🔍 Поиск

### Главная страница
Поиск работает по:
- Названиям разделов
- Описаниям
- Ключевым словам (data-keywords)
- Названиям ссылок

### API вьюер
Поиск работает по:

- Описаниям

## 🎯 Рекомендации по использованию

### Для менеджеров продукта
1. Начните с `index.html`
2. Изучите раздел "Обзор проекта"
3. Просмотрите "Игровые модули" для понимания функционала
4. Используйте поиск для быстрого нахождения информации

### Для разработчиков
1. Откройте `api/api-viewer.html` или `api/swagger-ui.html`
2. Изучите REST API endpoints
3. Просмотрите Socket.IO события
4. Используйте `viewer.html` для технической документации

### Для дизайнеров
1. Откройте `viewer.html?file=technical/DESIGN.md`
2. Изучите дизайн систему
3. Просмотрите UI компоненты в `technical/CLIENT.md`

### Для тестировщиков
1. Изучите `api/API-EXAMPLES.md` через `viewer.html`
2. Просмотрите игровую логику в `technical/GAMES.md`
3. Используйте API вьюер для понимания endpoints

## 🔗 Интеграция

### Ссылки между документами
Все ссылки в Markdown автоматически работают:
```markdown
[Другой документ](../technical/AUTH.md)
```

### Якорные ссылки
Автоматически генерируются для заголовков:
```markdown
## Заголовок раздела
```
Становится: `#заголовок-раздела`

### Внешние ссылки
Открываются в новой вкладке (можно настроить)

## 💡 Советы и трюки

### Быстрая навигация
- Используйте Ctrl+F для поиска на странице
- Добавьте `index.html` в закладки
- Используйте боковую навигацию для быстрого перехода

### Печать документации
- Нажмите кнопку "🖨️ Печать" в viewer.html
- Или используйте Ctrl+P
- Стили оптимизированы для печати

### Офлайн использование
- Все вьюеры работают без интернета
- Только Marked.js загружается с CDN
- Можно скачать Marked.js локально при необходимости

## 🐛 Известные ограничения

1. **Marked.js CDN**: Требует интернет для первой загрузки
2. **Относительные пути**: Должны быть корректными относительно HTML файла
3. **Большие файлы**: Markdown файлы > 1MB могут загружаться медленно
