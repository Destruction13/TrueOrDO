## 📖 Как пользоваться документацией

### Шаг 1: Откройте главную страницу

Просто откройте файл **`docs/home.html`** в любом браузере:

- **Windows**: Двойной клик по файлу
- **Mac**: Двойной клик или `open docs/home.html`
- **Linux**: `xdg-open docs/home.html`

### Шаг 2: Выберите раздел

На главной странице вы увидите 9 красивых карточек:

1. **📖 Обзор проекта** — начните отсюда, если вы новичок
2. **🎮 Игры** — узнайте о всех 4 играх
3. **🔐 Вход и регистрация** — как создать аккаунт
4. **👥 Друзья и кланы** — социальные функции
5. **💎 VIP и PRO** — премиум возможности
6. **📈 Достижения** — система уровней
7. **📡 API для разработчиков** — техническая документация
8. **🎨 Дизайн и интерфейс** — UI компоненты
9. **📊 Схемы и диаграммы** — визуальная архитектура

### Шаг 3: Читайте и наслаждайтесь!

Каждая страница содержит:
- ✅ Красивое оформление

## 🔧 Обновление документации

Если вы разработчик и хотите обновить документацию:

### 1. Отредактируйте Markdown файл

```bash
# Откройте нужный .md файл в редакторе
code docs/OVERVIEW.md
```

### 2. Перегенерируйте HTML

```bash
# Запустите скрипт генерации
node scripts/build-docs-site.js
```

### 3. Обновите браузер

Просто обновите страницу (F5) — изменения отобразятся сразу!
