# API Документация

Эта папка содержит всю документацию по API проекта.

## Содержание

- `openapi.yaml` - OpenAPI спецификация
- `swagger-ui.html` - Интерактивный Swagger UI
- `API-REFERENCE.md` - Полный справочник API
- `API-EXAMPLES.md` - Примеры использования API
- `SWAGGER-USAGE.md` - Руководство по использованию Swagger

## Быстрый старт

1. Откройте `swagger-ui.html` для интерактивного просмотра API
2. Изучите `API-EXAMPLES.md` для практических примеров
3. Используйте `API-REFERENCE.md` как полный справочник
