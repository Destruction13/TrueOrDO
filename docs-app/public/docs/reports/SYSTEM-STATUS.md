## 🚀 Как использовать

### Для просмотра документации:
1. Откройте файл `docs/home.html` в любом браузере
2. Кликните на любую карточку для перехода в раздел
3. Используйте боковое меню для навигации между разделами

### Для обновления документации:
1. Отредактируйте нужный `.md` файл в папке `docs/`
2. Запустите генератор:
   ```bash
   node scripts/build-docs-site.js
   ```
3. Обновите страницу в браузере

## 🔧 Техническое решение проблемы CORS

**Проблема**: При использовании `fetch()` для загрузки `.md` файлов возникала ошибка CORS при открытии через `file://` протокол.

**Решение**: 
- Markdown контент читается во время **build time** (при запуске скрипта)
- Контент экранируется и встраивается в HTML как JavaScript template literal
- При загрузке страницы markdown парсится библиотекой `marked.js`
- Результат: полностью автономные HTML файлы, работающие без сервера
