# Техническая Документация

Документация по техническим модулям и компонентам системы.

## Модули

- `AUTH.md` - Система аутентификации и авторизации
- `CLIENT.md` - Клиентская часть приложения
- `SERVER.md` - Серверная часть приложения
- `DATABASE.md` - Структура базы данных
- `GAMES.md` - Игровые модули
- `SOCIAL.md` - Социальные функции
- `STATS.md` - Система статистики
- `SUBSCRIPTION.md` - Система подписок
- `DESIGN.md` - Дизайн система
- `DEPLOY.md` - Развертывание и деплой

Каждый модуль доступен в форматах `.md` и `.html`.
