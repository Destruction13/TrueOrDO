# 📚 Документация TrueOrDO

Добро пожаловать в документацию проекта TrueOrDO!

## 🗂️ Структура документации

Документация организована по следующим категориям:

### 📁 [api/](api/)
Полная документация API с OpenAPI спецификацией, Swagger UI и примерами использования.

- `openapi.yaml` - OpenAPI спецификация
- `swagger-ui.html` - Интерактивный Swagger UI
- `API-REFERENCE.md` - Полный справочник API
- `API-EXAMPLES.md` - Примеры использования

### 📁 [technical/](technical/)
Техническая документация по модулям и компонентам системы.

- `AUTH.md` - Аутентификация и авторизация
- `CLIENT.md` - Клиентская часть
- `SERVER.md` - Серверная часть
- `DATABASE.md` - База данных
- `GAMES.md` - Игровые модули
- `SOCIAL.md` - Социальные функции
- `STATS.md` - Статистика
- `SUBSCRIPTION.md` - Подписки
- `DESIGN.md` - Дизайн система
- `DEPLOY.md` - Развертывание

### 📁 [guides/](guides/)
Руководства и инструкции для работы с проектом.

- `START-HERE.md` - Начните отсюда
- `ИНСТРУКЦИЯ.md` - Основная инструкция
- `DOCS-GUIDE.md` - Руководство по документации
- `MCP-SETUP.md` - Настройка MCP

### 📁 [overview/](overview/)
Обзорная документация, диаграммы и индексы.

- `OVERVIEW.md` - Общий обзор проекта
- `DIAGRAMS.md` - Диаграммы и схемы
- `INDEX.md` - Индекс документации

### 📁 [reports/](reports/)
Отчеты о выполнении задач, верификации и статусе системы.

- `SYSTEM-STATUS.md` - Текущий статус
- `FINAL-COMPLETION-REPORT.md` - Финальный отчет
- `VERIFICATION-REPORT-*.md` - Отчеты верификации

### 📁 [viewers/](viewers/)
HTML-просмотрщики для интерактивного просмотра документации.

- `INDEX.html` - Главная страница
- `viewer.html` - Универсальный просмотрщик
- `doc-viewer.html` - Просмотрщик документов

## 🚀 Быстрый старт

**[QUICK-START.md](QUICK-START.md)** - Инструкция для быстрого начала работы с документацией

1. **Новичкам**: Откройте [index.html](index.html) в браузере
2. **Разработчикам**: Изучите [api/swagger-ui.html](api/swagger-ui.html) или [api/api-viewer.html](api/api-viewer.html)
3. **Архитекторам**: Смотрите [overview/OVERVIEW.md](overview/OVERVIEW.md)
4. **Всем**: Используйте [viewer.html](viewer.html) для просмотра любых документов

## 📝 Форматы

Большинство документов доступны в двух форматах:
- `.md` - Markdown для чтения в редакторе
- `.html` - HTML для просмотра в браузере
