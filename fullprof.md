## Этапы разработки

### Этап 1: Создание базовой структуры модалки

**Файл: `FullProfileModal.jsx`**

- Модальное окно с overlay (использовать `createPortal`)
- Двухколоночный layout (CSS Grid или Flexbox)
- Анимация открытия/закрытия (Framer Motion)
- Закрытие по клику на overlay и по Escape
- Props: `targetUserId`, `socket`, `currentUserId`, `onClose`

**Стили:**

- Тёмная тема в стиле существующего UI
- Responsive: на мобильных — одноколоночный layout со скроллом
- Ширина модалки: ~900px (desktop), 100% (mobile)

### Этап 2: Левая панель — FullProfileSidebar

**Компоненты из MiniProfile для переиспользования:**

1. ✅ Аватар с рамкой (`AvatarFrame`)
2. ✅ Точка статуса онлайн (зелёная/жёлтая/красная/серая)
3. ✅ Никнейм со стилизацией (`StyledNickname`)
4. ✅ Бейдж уровня
5. ✅ Тег пользователя (кликабельный для копирования)
6. ✅ Статус "о себе" — облако мыслей (`BioStatus`)

**Что НЕ включать (в отличие от MiniProfile):**

- ❌ Любимые игры
- ❌ Достижения (будут на вкладке "Достижения")

**Дополнительные элементы (по референсу):**

- Кнопка "Редактировать профиль" (для своего профиля)
- Кнопка друзей (добавить/принять/написать)
- Блок "В числе участников с" — дата регистрации
- Блок "Заметка" — приватная заметка о пользователе (только для себя)

```js

  // ... существующие поля

    type: "streaming",  // или "playing", "idle"
    roomName: "Love Room 💕",
    gameType: "tod",
    participants: [{ id, nickname, avatar }]
  },
  recentActivity: [
    {
      id: "...",
      gameType: "tod",
      activityType: "played",  // played, marathon, achievement
      timestamp: "2026-02-20T15:30:00Z",
      duration: 180,  // минуты

    }
  ]
}
```
