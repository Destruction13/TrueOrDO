---
description: Запускает локальный сервер базы данных, Backend и Frontend для разработки.
---

1. Запускаем сервер (Backend):
// turbo
```bash
cd server ; npm run dev
```

2. Запускаем клиент (Frontend):
// turbo
```bash
cd client ; npm run dev
```

> [!TIP]
> Сервер и Клиент запустились в фоновом режиме. Вы можете проверить статус выполнения или остановить их в любой момент через инструменты управления терминалом. Агент в любой момент может прочитать логи из этих терминалов, чтобы помочь с отладкой.
