6. Тёмно-синий: `#30cfd0 → #330867`

8. Персиковый: `#ff9a9e → #fecfef`
9. Бежевый: `#ffecd2 → #fcb69f`

### Типографика

**Шрифты:**
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 
             'Helvetica Neue', Arial, sans-serif;
```

**Размеры:**
- H1: 3.5rem (главная), 2.8rem (страницы)
- H2: 2rem
- H3: 1.5rem
- Текст: 1.05rem
- Описания: 1rem

### Анимации

**Появление карточек:**
```css
@keyframes fadeInUp {
    from { opacity: 0; transform: translateY(30px); }
    to { opacity: 1; transform: translateY(0); }
}
```

**Задержки:** 0.1s, 0.2s, 0.3s... для последовательного появления

**Hover эффекты:**
- Подъём карточки: `translateY(-10px)`
- Увеличение: `scale(1.02)`
- Тень: `0 20px 60px rgba(0,0,0,0.25)`

## 🚀 Использование

### Локальный просмотр

```bash
# Вариант 1: Просто откройте в браузере
open docs/home.html

# Вариант 2: Через HTTP сервер
cd docs
http-server -p 8080
# Откройте http://localhost:8080/home.html

# Вариант 3: Через VS Code Live Server
# Установите расширение "Live Server"
# Откройте home.html и нажмите "Go Live"
```

### Деплой на сервер

**Nginx конфигурация:**
```nginx
location /docs {
    alias /path/to/TrueOrDO/docs;
    index home.html;
    try_files $uri $uri/ =404;
}
```

**Доступ:** `https://partychaos.ru/docs`

## 🔄 Обновление документации

### Редактирование контента

1. Отредактируйте `.md` файл
2. Откройте `home.html` в браузере
3. Изменения отобразятся автоматически

### Добавление раздела

1. Создайте новый `.md` файл
2. Добавьте карточку в `home.html`
3. Добавьте ссылку в `doc-viewer.html`
4. Запустите `node scripts/generate-html-docs.js`

### Изменение дизайна

1. Откройте `home.html` или `doc-viewer.html`
2. Найдите нужный CSS
3. Измените цвета/шрифты/размеры
4. Сохраните и обновите браузер
