## 🔧 Техническое решение

### Проблема CORS

**Изначальная проблема:**
При попытке загрузить `.md` файлы через `fetch()` возникала ошибка:
```
Access to fetch at 'file:///...' from origin 'null' has been blocked by CORS policy
```

**Решение:**
1. Markdown контент читается во время **build time**
2. Контент экранируется для безопасной вставки в JavaScript
3. Встраивается в HTML как template literal
4. При загрузке страницы парсится библиотекой `marked.js`

**Преимущества:**
- ✅ Работает без HTTP сервера
- ✅ Работает офлайн
- ✅ Быстрая загрузка
- ✅ Нет зависимостей от сервера

### Используемые библиотеки (CDN)

```javascript
// Парсинг markdown
marked.js v11.1.1

// Диаграммы
mermaid.js v10.6.1

// Подсветка кода
highlight.js v11.9.0 (тема: Atom One Dark)
```
