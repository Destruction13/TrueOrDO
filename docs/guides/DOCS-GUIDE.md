# 🎯 Руководство по использованию документации PartyChaos

## 🚀 Как открыть документацию

### Способ 1: Локально (рекомендуется)

1. Откройте файл `docs/home.html` в любом браузере
2. Выберите нужный раздел
3. Готово! 🎉

### Способ 2: Через локальный сервер

```bash
# Установите простой HTTP сервер (если ещё не установлен)
npm install -g http-server

# Запустите сервер в папке docs
cd docs
http-server -p 8080

# Откройте в браузере
# http://localhost:8080/home.html
```

### Способ 3: Через VS Code

1. Установите расширение "Live Server"
2. Откройте `docs/home.html`
3. Нажмите "Go Live" в правом нижнем углу

## 📖 Навигация по документации

### Главная страница (home.html)

Красивая страница с карточками всех разделов:

- **Обзор проекта** — общая информация
- **Игры** — описание всех 4 игр
- **Аутентификация** — вход и регистрация
- **Социальные функции** — друзья, чаты, кланы
- **Подписка** — VIP и PRO возможности
- **Статистика** — достижения и лидеры
- **API для разработчиков** — техническая документация
- **Дизайн** — UI компоненты
- **Диаграммы** — визуальные схемы

### Страница раздела (doc-viewer.html)

Каждый раздел открывается в красивом viewer с:

- **Боковым меню** — быстрая навигация между разделами
- **Подсветкой кода** — все примеры красиво оформлены
- **Интерактивными диаграммами** — Mermaid схемы
- **Адаптивным дизайном** — работает на всех устройствах
