### Как обновить документацию

1. **Отредактируйте нужный `.md` файл**
   ```bash
   # Например, откройте в редакторе
   code docs/GAMES.md
   ```

2. **Запустите генератор HTML**
   ```bash
   node scripts/build-docs-site.js
   ```

3. **Проверьте результат**
   ```bash
   node scripts/verify-docs.js
   ```

4. **Откройте в браузере**
   ```bash
   start docs/home.html
   ```

### Как работает генератор

Скрипт `scripts/build-docs-site.js`:
1. Читает все `.md` файлы из папки `docs/`
2. Экранирует markdown контент
3. Встраивает его в HTML шаблон
4. Сохраняет готовые `.html` файлы

**Преимущества:**
- ✅ Нет проблем с CORS
- ✅ Работает без сервера
- ✅ Быстрая загрузка
- ✅ Полностью автономно

## 🔧 Решение проблем

### Проблема: Страница не открывается

**Решение:**
1. Убедитесь что файл `home.html` существует
2. Попробуйте открыть через браузер напрямую (Ctrl+O)
3. Проверьте что путь правильный: `C:\AI\Bots\TrueOrDO\docs\home.html`

### Проблема: Контент не отображается

**Решение:**
1. Проверьте что у вас есть интернет (для загрузки библиотек)
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Попробуйте другой браузер (Chrome, Firefox, Edge)

### Проблема: Устаревший контент

**Решение:**
1. Отредактируйте нужный `.md` файл
2. Запустите: `node scripts/build-docs-site.js`
3. Обновите страницу в браузере (F5 или Ctrl+R)

### Проблема: Ошибка при генерации

**Решение:**
1. Проверьте что Node.js установлен: `node --version`
2. Убедитесь что вы в корне проекта
3. Проверьте что файл существует: `ls scripts/build-docs-site.js`
4. Запустите проверку: `node scripts/verify-docs.js`
