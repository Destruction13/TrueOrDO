## 🚀 Быстрый старт

### Разработка (локально)

```bash
# Установка зависимостей
npm install

# Миграции БД
npm run db:migrate

# Загрузка seed-контента
npm run db:seed

# Запуск dev-сервера (клиент + сервер)
npm run dev
```

Откройте `http://localhost:5173`

### Production

```bash
# Сборка клиента
npm run build

# Запуск сервера (API + статика)
npm run start
```

Подробнее: [Деплой и настройка](./DEPLOY.md)

## 🛠️ Технологии

### Frontend
- **React 18** — UI библиотека
- **Vite** — сборщик и dev-сервер
- **React Router** — клиентский роутинг
- **Socket.IO Client** — WebSocket соединение
- **Framer Motion** — анимации
- **Three.js / React Three Fiber** — 3D графика
- **@paper-design/shaders-react** — шейдеры для фонов

### Backend
- **Express.js** — веб-сервер
- **Socket.IO** — WebSocket сервер
- **Prisma ORM** — работа с БД
- **SQLite** — база данных
- **bcryptjs** — хеширование паролей
- **Nodemailer** — отправка email
- **Multer** — загрузка файлов

### Инфраструктура
- **PM2** — процесс-менеджер (production)
- **Nginx** — reverse proxy + SSL
- **Let's Encrypt** — SSL сертификаты
- **Ubuntu 24.04** — операционная система (VPS)
