## 🚀 Как начать использовать

### Шаг 1: Откройте главную страницу
```
Откройте файл docs/index.html в браузере
```

### Шаг 2: Изучите интерфейс
- Используйте поиск для фильтрации
- Кликайте на карточки разделов
- Используйте быстрые ссылки

### Шаг 3: Просмотрите документы
- Для Markdown: используйте viewer.html
- Для API: используйте api/api-viewer.html
- Для интерактивного API: используйте api/swagger-ui.html

### Шаг 4: Добавьте в закладки
```
Ctrl+D (Windows) / Cmd+D (Mac)
```
