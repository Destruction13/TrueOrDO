# Система подписки

## 💎 Обзор

PartyChaos предлагает два уровня платной подписки:
- **VIP** — базовые преимущества
- **PRO** — расширенные возможности

---

## 📋 Тарифы

### Free (бесплатно)

**Возможности:**
- Все игры без ограничений
- Базовые рамки аватара
- Базовые цвета никнейма
- Создание/вступление в кланы
- Друзья и чаты

---

### VIP

**Цена:** 199₽/месяц, 1990₽/год

**Преимущества:**
- ✨ Эксклюзивные рамки аватара (20+ дизайнов)
- 🎨 Градиенты для никнейма (15+ вариантов)
- 💫 Эффекты свечения никнейма (10+ вариантов)
- 🏆 Бейдж VIP в профиле
- 📊 Расширенная статистика
- 🎯 Приоритетная поддержка

---

### PRO

**Цена:** 399₽/месяц, 3990₽/год

**Преимущества:**
- ✅ Все преимущества VIP
- 🌟 Анимированные эффекты никнейма (5+ вариантов)
- 🎭 Эксклюзивные PRO рамки (10+ дизайнов)
- 🔥 Уникальные анимации в играх
- 👑 Бейдж PRO в профиле
- 🎨 Кастомные цвета для никнейма (любой HEX)
- 📈 Детальная аналитика игр
- 🎁 Ежемесячные бонусы

## 🔌 API Endpoints

### Статус подписки

**GET** `/api/subscription/status`

**Response:**
```json
{
  "subscription": {
    "tier": "vip",
    "status": "active",
    "startsAt": "2024-01-01T00:00:00.000Z",
    "expiresAt": "2024-12-31T23:59:59.999Z"
  }
}
```

---

### Создание подписки

**POST** `/api/subscription/create`

**Body:**
```json
{
  "tier": "vip",
  "duration": "month"
}
```

**Response:**
```json
{
  "paymentUrl": "https://tribute.tg/pay/..."
}
```

**Процесс:**
1. Создание Payment в БД
2. Создание платежа в Tribute
3. Возврат ссылки на оплату

---

### Отмена подписки

**POST** `/api/subscription/cancel`

**Response:**
```json
{
  "success": true,
  "message": "Подписка отменена"
}
```

**Эффект:**
Подписка будет активна до конца оплаченного периода, но не продлится автоматически.

---

## 💳 Интеграция с Tribute

### Webhook

**POST** `/api/subscription/payments/webhook`

**Body:**
```json
{
  "event": "payment.succeeded",
  "payment": {
    "id": "payment-id",
    "amount": 199,
    "currency": "RUB",
    "status": "succeeded",
    "metadata": {
      "userId": "user-id",
      "tier": "vip",
      "duration": "month"
    }
  }
}
```

**Процесс:**
1. Проверка подписи webhook
2. Поиск Payment в БД
3. Обновление статуса Payment
4. Создание/продление Subscription
5. Уведомление пользователя

## 🎨 Кастомизация

### Рамки аватара

**Доступ:**
- Free: 5 базовых рамок
- VIP: +20 эксклюзивных рамок
- PRO: +10 PRO рамок

**Выбор рамки:**
```javascript
// Клиент
socket.emit("customization:frame:set", {
  game: "alias", // "all" | "alias" | "codenames" | "tod" | "emotional"
  frameSlug: "cyberpunk"
});
```

---

### Кастомизация никнейма

**Типы:**
- `basic` — базовый цвет (Free)
- `custom` — кастомный HEX цвет (PRO)
- `gradient` — градиент (VIP/PRO)

**Эффекты:**
- `glow` — свечение (VIP/PRO)
- `animated` — анимация (PRO)

**Пример:**
```javascript
// Клиент
socket.emit("customization:nickname:set", {
  colorType: "gradient",
  gradientId: "gradient-id",
  glowId: "glow-id",
  effectId: "effect-id" // Только PRO
});
```

## 🔄 Автопродление

Подписка автоматически продлевается через Tribute:
- За 3 дня до окончания отправляется уведомление
- При успешной оплате подписка продлевается
- При неудаче отправляется уведомление
