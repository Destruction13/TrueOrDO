# Игровые модули

## 🎮 Обзор игр

PartyChaos включает 4 полностью реализованные многопользовательские игры с real-time синхронизацией через WebSocket.

---

## 1. Правда или Действие (Truth or Dare)

### Описание

Классическая игра для вечеринок с современным подходом. Игроки по очереди выбирают "Правда" или "Действие", крутят два колеса (категория → задание), выполняют задание и получают оценку от других игроков.

### Особенности

- **До 20 игроков** в одной комнате
- **Два колеса выбора**: категория (4 варианта) → задание (12 вариантов на категорию)
- **Таймер** на выполнение задания (настраиваемый)
- **Система голосования**: "Да" / "Нет" / "Репорт"
- **Страйки**: 2 страйка = дисквалификация
- **Режим "Chaos"**: наказание для игроков с плохим поведением
- **Режим "Shamed"**: временное наказание за отказ от задания

### Игровой процесс

1. **Создание комнаты**: ведущий создаёт комнату и получает код
2. **Присоединение**: игроки вводят код и присоединяются
3. **Выбор**: текущий игрок выбирает "Правда" или "Действие"
4. **Колесо 1**: крутится колесо категорий (Позвонить, Написать, Сделать, Сказать)
5. **Колесо 2**: крутится колесо заданий (12 вариантов для выбранной категории)
6. **Таймер**: запускается таймер на выполнение
7. **Голосование**: все игроки (кроме текущего) голосуют за результат
8. **Результат**: 
   - Большинство "Да" → успех, переход к следующему игроку
   - Большинство "Нет" → провал, страйк
   - Большинство "Репорт" → страйк за неподобающее поведение
   - Ничья → не засчитано, повтор хода
9. **Дисквалификация**: при 2 страйках игрок выбывает

### Категории и задания

#### Категория "Позвонить" (12 заданий)
- Позвонить знакомому и сказать что-то необычное
- Позвонить в поддержку и задать странный вопрос
- Примеры: "Честное мнение", "Вклад 37 рублей", "Жидкий суп"

#### Категория "Написать" (12 заданий)
- Отправить сообщение с необычным содержанием
- Написать в чат поддержки
- Примеры: "Комплимент бывшему", "Признание родителям", "Странный вопрос"

#### Категория "Сделать" (12 заданий)
- Физические действия
- Челленджи
- Примеры: "Танец без музыки", "Селфи с незнакомцем", "Планка 60 секунд"

#### Категория "Сказать" (12 заданий)
- Вербальные задания
- Признания
- Примеры: "Самый стыдный момент", "Тайна", "Комплимент всем"

### Режимы наказания

#### Shamed (Пристыженный)
- Получает язвительный титул (например, "Главный мастер сливов")
- Может снять статус, выполнив 3 задания подряд
- Не может отказываться от заданий

#### Chaos (Хаос)
- Получает особо сложные задания
- Может снять статус, выполнив 3 chaos-задания подряд
- Задания из специального набора "chaos"

### Технические детали

#### Серверная логика (`server/src/game/wheels.js`)

```javascript
// Структура комнаты
{
  id: "room-id",
  code: "ABC123",
  hostId: "player-id",
  players: [
    {
      id: "player-id",
      name: "Player 1",
      avatarUrl: "...",
      status: "active", // "active" | "shamed" | "chaos" | "disqualified"
      strikes: 0,
      connectionStatus: "online" // "online" | "disconnected" | "left"
    }
  ],
  settings: {
    timerSeconds: 60,
    allowSkip: false
  }
}
```

#### Socket.IO события

**Создание и присоединение:**
- `tod:create` → создать комнату
- `tod:join` → присоединиться к комнате
- `tod:leave` → покинуть комнату

**Игровой процесс:**
- `tod:choice` → выбор "truth" или "dare"
- `tod:spin:wheel1` → крутить колесо категорий
- `tod:spin:wheel2` → крутить колесо заданий
- `tod:timer:start` → запустить таймер
- `tod:timer:reset` → сбросить таймер
- `tod:vote` → проголосовать ("yes" | "no" | "report")
- `tod:round:skip` → пропустить раунд (только ведущий)

**Broadcast события:**
- `tod:room:state` → обновление состояния комнаты
- `tod:spin:wheel1:result` → результат колеса 1
- `tod:spin:wheel2:result` → результат колеса 2
- `tod:timer:tick` → тик таймера
- `tod:round:complete` → раунд завершён

- `WheelsJoinScreen.jsx` — экран создания/присоединения
- `WheelsRoomScreen.jsx` — главный экран игры
- `WheelSpinner.jsx` — анимация колеса
- `PlayerList.jsx` — список игроков
- `VotingPanel.jsx` — панель голосования
- `RoundResult.jsx` — результат раунда

## 2. Alias (Шляпа)

### Описание

Командная игра на объяснение слов. Игроки делятся на команды, по очереди объясняют слова своей команде, зарабатывая очки. Первая команда, набравшая целевой счёт, побеждает.

### Особенности

- **Неограниченное количество команд** (минимум 2)
- **3 уровня сложности**: лёгкий (~4000 слов), средний (~6600 слов), сложный (~2000 слов)
- **Настраиваемый таймер**: 30-120 секунд на ход
- **Целевой счёт**: 10-100 очков
- **Штраф за пропуск**: 0 или -1 очко (настраивается)
- **Система готовности**: все игроки должны нажать "Готов" перед стартом
- **Пауза**: ведущий может поставить игру на паузу
- **CyberRunner**: анимированный фон с бегущим текстом

### Игровой процесс

1. **Создание комнаты**: ведущий создаёт комнату и настраивает параметры
2. **Создание команд**: игроки создают команды (название + цвет)
3. **Присоединение к командам**: игроки выбирают команду
4. **Готовность**: все игроки нажимают "Готов"
5. **Старт игры**: ведущий запускает игру
6. **Ход команды**:
   - Объясняющий видит слово
   - Остальные игроки команды угадывают
   - Объясняющий нажимает "Угадали" (+1) или "Пропустить" (0 или -1)
   - Таймер отсчитывает время
7. **Смена хода**: после истечения таймера ход переходит к следующей команде
8. **Победа**: первая команда, набравшая целевой счёт, побеждает

### Уровни сложности

#### Лёгкий (~4000 слов)
Простые, часто используемые слова:
- Дом, Кот, Машина, Телефон, Книга
- Солнце, Дождь, Снег, Ветер
- Мама, Папа, Друг, Учитель

#### Средний (~6600 слов)
Более сложные слова и понятия:
- Архитектура, Философия, Демократия
- Инновация, Компромисс, Парадокс
- Метафора, Аллегория, Синоним

#### Сложный (~2000 слов)
Редкие и специфические слова:
- Эфемерный, Апокалипсис, Меланхолия
- Гипербола, Катарсис, Эмпатия
- Абстракция, Дихотомия, Синергия

## 3. Codenames (Кодовые имена)

### Описание

Командная игра с подсказками. Две команды (красная и синяя) соревнуются в угадывании своих слов на поле 5x5. Капитан даёт подсказку (слово + число), оперативники выбирают карточки. Побеждает команда, первой открывшая все свои карточки.

### Особенности

- **Две команды**: красная и синяя
- **Роли**: капитан (даёт подсказки) и оперативники (угадывают)
- **Поле 5x5**: 25 карточек (9 красных, 8 синих, 7 нейтральных, 1 убийца)
- **Таймеры фаз**: 
  - Первая подсказка: 120 секунд
  - Подсказка: 60 секунд (потом overtime)
  - Угадывание: 60 секунд + 10 секунд за правильное угадывание
- **Система подтверждения**: 2 секунды на подтверждение выбора карточки
- **Пауза**: ведущий может поставить игру на паузу

### Игровой процесс

1. **Создание комнаты**: ведущий создаёт комнату
2. **Выбор команды**: игроки присоединяются к красной или синей команде
3. **Выбор роли**: игроки выбирают роль (капитан / оперативник / зритель)
4. **Старт игры**: ведущий запускает игру, генерируется поле 5x5
5. **Ход команды**:
   - **Фаза подсказки**: капитан даёт подсказку (слово + число)
   - **Фаза угадывания**: оперативники выбирают карточки
   - **Подтверждение**: 2 секунды на подтверждение выбора
   - **Результат**:
     - Своя карточка → +1 очко, можно продолжать
     - Чужая карточка → +1 очко противнику, ход переходит
     - Нейтральная → ход переходит
     - Убийца → мгновенное поражение
6. **Победа**: первая команда, открывшая все свои карточки, побеждает

### Типы карточек

- **Красные** (9 шт.) — карточки красной команды
- **Синие** (8 шт.) — карточки синей команды
- **Нейтральные** (7 шт.) — не приносят очков
- **Убийца** (1 шт.) — мгновенное поражение

## 4. Emotional Intelligence

### Описание

Игра на угадывание эмоций. Ведущий выбирает эмоцию, игроки видят слова-ассоциации и пытаются угадать эмоцию. После угадывания все голосуют за лучшее объяснение. Игрок с наибольшим количеством очков побеждает.

### Особенности

- **Овальный стол**: игроки расположены вокруг стола
- **Категории эмоций**: радость, грусть, страх, гнев, удивление, отвращение
- **Слова-ассоциации**: 3-5 слов для каждой эмоции
- **Система голосования**: игроки голосуют за лучшее объяснение
- **Автопереход раундов**: после голосования автоматически начинается новый раунд
- **Таблица лидеров**: отображает счёт всех игроков

### Игровой процесс

1. **Создание комнаты**: ведущий создаёт комнату
2. **Присоединение**: игроки присоединяются к комнате
3. **Старт игры**: ведущий запускает игру
4. **Раунд**:
   - **Выбор эмоции**: ведущий выбирает эмоцию (скрыта от других)
   - **Слова-ассоциации**: игроки видят 3-5 слов
   - **Угадывание**: игроки пытаются угадать эмоцию
   - **Голосование**: все голосуют за лучшее объяснение
   - **Результат**: игрок с наибольшим количеством голосов получает очко
5. **Победа**: игрок с наибольшим количеством очков после N раундов побеждает

### Категории эмоций

- **Радость**: счастье, восторг, удовольствие, веселье
- **Грусть**: печаль, тоска, уныние, меланхолия
- **Страх**: тревога, ужас, паника, беспокойство
- **Гнев**: злость, ярость, раздражение, негодование
- **Удивление**: изумление, шок, недоумение, восхищение
- **Отвращение**: брезгливость, неприязнь, омерзение

## 🎯 Общие механики

### Система комнат

Все игры используют единую систему комнат:
- **Код комнаты**: 6 символов (A-Z, 2-9, без похожих символов)
- **Ведущий**: создатель комнаты, имеет расширенные права
- **Присоединение**: по коду комнаты
- **Автоочистка**: комнаты удаляются при отключении всех игроков

### Синхронизация

- **WebSocket (Socket.IO)**: real-time синхронизация состояния
- **Broadcast**: обновления отправляются всем игрокам в комнате
- **Reconnect**: автоматическое переподключение при разрыве связи

### Статистика

После каждой игры записывается статистика:
- Количество сыгранных игр
- Количество побед
- Общее время в игре
- Специфичные метрики для каждой игры

### Достижения

Игроки получают достижения за:
