# HTML Вьюеры документации

Эта папка содержит HTML-интерфейсы для просмотра документации TrueOrDO.

## 🎨 Главный вьюер (РЕКОМЕНДУЕТСЯ)

**[../index.html](../index.html)** - Главная страница документации с современным дизайном
- Красивый интерфейс с градиентами и анимациями
- Поиск по всей документации
- Быстрые ссылки на важные разделы
- Статистика проекта
- Адаптивный дизайн для всех устройств

## 📖 Универсальный вьюер

**[../viewer.html](../viewer.html)** - Просмотр любых Markdown файлов
- Автоматическое оглавление
- Подсветка синтаксиса
- Красивое форматирование таблиц и кода
- Использование: `viewer.html?file=путь/к/файлу.md`

## 📡 API Вьюер

**[../api/api-viewer.html](../api/api-viewer.html)** - Интерактивный API Reference
- Визуальное отображение endpoints
- Цветовая кодировка HTTP методов
- Поиск по API
- Примеры запросов и ответов
- Навигация по Socket.IO событиям

## 📂 Старые вьюеры (устаревшие)

- `INDEX.html` - Старая главная страница
- `INDEX-DOC.html` - Старый индекс документов
- `home.html` - Старая домашняя страница
- `viewer.html` - Старый просмотрщик
- `doc-viewer.html` - Старый просмотрщик документов

**Примечание**: Рекомендуется использовать новые вьюеры в корне папки docs.

## 🚀 Как использовать

1. Откройте `../index.html` в браузере
2. Используйте поиск для быстрого нахождения нужной информации
3. Кликайте на ссылки для навигации по документации
4. Для просмотра конкретного Markdown файла используйте `../viewer.html?file=путь.md`

## 🎨 Дизайн

Все новые вьюеры используют единый дизайн:
- Темная тема с градиентами
- Цветовая схема: фиолетовый (#6366f1) и пурпурный (#8b5cf6)
- Плавные анимации и переходы
- Адаптивная верстка
- Удобная типографика для нетехнических специалистов

- ✅ Firefox
