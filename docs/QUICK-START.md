# 🚀 Быстрый старт с документацией TrueOrDO

## Для нетехнических специалистов

### 1️⃣ Откройте документацию

Просто откройте файл **`index.html`** в браузере (двойной клик на файл).

Вы увидите красивую главную страницу со всеми разделами документации.

### 2️⃣ Используйте поиск

В верхней части страницы есть поле поиска 🔍. Введите ключевое слово, и система покажет только релевантные разделы.

**Примеры поиска:**
- `api` - найдет всю API документацию
- `игры` - покажет игровые модули
- `подписка` - информация о подписках
- `друзья` - социальные функции

### 3️⃣ Навигация

Кликайте на карточки разделов для перехода к нужной документации. Каждая карточка содержит:
- 📁 Название раздела
- 📝 Краткое описание
- 🔗 Ссылки на документы

### 4️⃣ Быстрые ссылки

В верхней части главной страницы есть 4 кнопки быстрого доступа:
- **🚀 Быстрый старт** - начните отсюда
- **📡 API Reference** - для разработчиков
- **🗺️ Обзор проекта** - общая информация
- **🎮 Игровые модули** - описание игр

## Для разработчиков

### API Documentation

1. Откройте **`api/swagger-ui.html`** для интерактивного API
2. Или используйте **`api/api-viewer.html`** для красивого просмотра
3. Полная документация в **`api/API-REFERENCE.md`**

### Техническая документация

Все технические документы находятся в папке **`technical/`**:
- `AUTH.md` - аутентификация
- `DATABASE.md` - структура БД
- `GAMES.md` - игровая логика
- `SERVER.md` - серверная часть
- `CLIENT.md` - клиентская часть

### Просмотр Markdown файлов

Используйте **`viewer.html?file=путь/к/файлу.md`** для красивого просмотра любого Markdown документа.

**Пример:**
```
viewer.html?file=technical/AUTH.md
```

## 🎨 Особенности интерфейса

### Темная тема
Все вьюеры используют приятную темную тему с фиолетовыми акцентами, которая не утомляет глаза.

### Адаптивность
Документация отлично выглядит на любых устройствах:
- 💻 Десктоп
- 📱 Планшет
- 📱 Смартфон

### Интерактивность
- Плавная прокрутка
- Анимации при наведении
- Автоматическое оглавление
- Подсветка активного раздела

## 🔖 Добавьте в закладки

Для быстрого доступа добавьте в закладки браузера:
1. Откройте `index.html`
2. Нажмите Ctrl+D (Cmd+D на Mac)
3. Сохраните закладку
