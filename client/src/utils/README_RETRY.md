# Retry Logic Utility

## Обзор

Утилита `retryWithBackoff` реализует механизм повторных попыток с экспоненциальной задержкой для критических операций.

## Использование

```javascript
import { retryWithBackoff } from './retryWithBackoff';

// Пример использования с Socket.IO
const result = await retryWithBackoff(async () => {
  return new Promise((resolve, reject) => {
    socket.emit('event:name', payload, (response) => {
      if (response?.success) {
        resolve(response);
      } else {
        reject(new Error(response?.error || 'Ошибка операции'));
      }
    });
  });
}, 3, 1000);
```

## Параметры

- `operation` (Function) - Асинхронная функция для выполнения
- `maxRetries` (number) - Максимальное количество попыток (по умолчанию: 3)
- `baseDelay` (number) - Базовая задержка в миллисекундах (по умолчанию: 1000)

## Алгоритм задержки

Экспоненциальная задержка: `delay = baseDelay * 2^attempt`

- Попытка 1: 1000ms * 2^0 = 1000ms (1 секунда)
- Попытка 2: 1000ms * 2^1 = 2000ms (2 секунды)
- Попытка 3: 1000ms * 2^2 = 4000ms (4 секунды)

## Обработка ошибок

### Сетевые ошибки (повторяются)
- Ошибки с ключевыми словами: network, timeout, connection, socket
- Коды ошибок: ECONNREFUSED, ETIMEDOUT
- Русские сообщения: "превышено время ожидания", "нет соединения"

### Ошибки валидации (НЕ повторяются)
- Ошибки с ключевыми словами: "валидац", "длин"
- Любые другие ошибки, не связанные с сетью

## Применение в проекте

### FriendNoteField
Используется для сохранения заметок о друзьях:
- Максимум 3 попытки
- Задержки: 1с, 2с, 4с
- Только для сетевых ошибок
- Ошибки валидации не повторяются

## Преимущества

1. **Надежность**: Автоматическое восстановление после временных сбоев
2. **Умная логика**: Различает сетевые ошибки и ошибки валидации
3. **Экспоненциальная задержка**: Снижает нагрузку на сервер
4. **Прозрачность**: Не требует изменений в коде операции

## Ограничения

- Не подходит для операций с побочными эффектами (если операция не идемпотентна)
- Увеличивает время выполнения при ошибках
- Требует правильной классификации ошибок
